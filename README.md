# Weather Application

## Project Overview
A web application that allows users to search weather information by city using Open-Meteo API.

## Technologies Used
- HTML
- CSS
- JavaScript
- Open-Meteo API

## AI Tools Used
- ChatGPT

## Prompts Used During Development
1. Create a weather application using Open-Meteo API.
2. Improve weather UI using CSS.
3. Add error handling for invalid city names.

## What I Learned
- API integration
- Fetch API
- Async/Await
- DOM Manipulation
- Git and GitHub workflow

## Features
- 5-Day Weather Forecast
- Current Location Detection (Geolocation)
- Search History using Local Storage
- Dark/Light Theme Toggle
- Temperature Unit Conversion (°C / °F)
- Dynamic Weather Backgrounds
- Weather Alerts and Recommendations
- AQI (Air Quality Index)
- UV Index
- Atmospheric Pressure
- Visibility Information
- Sunrise and Sunset Times
- Temperature Trend Chart using Chart.js
- Weather Animations (Clouds, Rain Effects)
